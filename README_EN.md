## Features

- 🎨 M3 dynamic color
- 🖼️ Wallpaper & frosted materials
- 🔊 Voice visualization
- 🌗 Day/night switch
- 🧩 Dockable workspace
- 🖥️ Right sidebar
- 🌐 Embedded browser
- 🎛️ Frameless window controls
- 🎯 Element picker
- ⚙️ 20 UI settings

Full features: [docs/features.md](docs/features.md) (Chinese).

## Install

```bash
pnpm install:desktop
pnpm patch:desktop  # optional: win32 frameless patch
```

See [docs/install.md](docs/install.md) (Chinese).
