# 字体优先级

打开「设置 → 外观 → 字体优先级」，通过页签分别配置界面与正文、代码、终端。面板沿用琉璃的亚克力、噪声、品牌色、圆角和阴影；优先字体带强调标记，字体项使用现有 Material 图标操作。

输入字体家族名后点「添加字体」，也可用逗号批量添加，例如 `Arial, MiSans, Microsoft YaHei`。输入区右侧打开原生 Menu 组件承载的磨砂字体菜单，选择后直接加入列表。每一项可上移、下移或移除，顺序从上到下代表 CSS `font-family` 的优先级，独立预览卡会即时更新。页签支持左右方向键及 Home / End，窄窗口使用容器查询调整间距。

浏览器会按字符选择列表中可用的字体：某个字体不存在或缺少字形时继续回退。列表支持本机字体和页面已经加载的 Web 字体，末尾始终保留默认字体栈与系统通用字体。正文标题使用同一套自定义优先级；代码和终端有各自独立的列表。

「默认回退字体」继续提供 MiSans 和内置系统栈。自定义字体优先于它们。每类列表的「恢复默认」只清空该类自定义优先级，其他两类保持原值。

字体偏好通过 DSH 原生 Theme 服务保存，与通用设置里的字体选项同步。支持 `text`、`code`、`terminal` 三个角色，不在琉璃快照中另存副本；刷新和重新启动后仍保留。

验证包含添加、去重、排序、移除、中文输入法组合期间不提交、原生设置持久化、角色隔离、页签键盘操作、320px 窄布局及实际浏览器字体回退。全部 29 项测试通过，安装包在准确版本 DSH 上冷启动，真实 Menu 的字体选择通过产品入口验证。
