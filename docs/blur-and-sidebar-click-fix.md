# 侧栏开合与点击修复

右侧栏开合时，外框连续伸缩，内部内容保持展开宽度，由外框裁剪显隐。原生侧栏通过同一时长、同一曲线的位移跟随外框，避免动画中反复测量位置、改写尺寸。

## 实现

- SidebarContent 在准备阶段确定内容宽度，开合期间固定尺寸，并暂停自身的尺寸观察；静止后恢复正常尺寸响应，手柄拖动仍能调整正文宽度。
- useSidebarPresence 管理准备、入场、展开、退场与关闭状态。退场完成后才折叠正文；快速反向点击取消旧任务，实际没有过渡时立即收尾。
- 交互锁放在琉璃自己的稳定外层，不写入上游面板。投影元数据暂时消失也不会留下无法点击的原生面板。
- 原有约 140ms 的磨砂渐隐、渐显保留，结束后还原配置值；辉光、阴影、噪点继续显示。声纹与手柄交互沿用既有实现。
- 几何扫描跳过 content-visibility 已跳过的屏外消息；菜单仅在打开时读取定位，固定菜单不再重复写入相同的根样式值。
- 噪点使用无损预栅格化的 PNG，保持原像素外观。

## 验证

```sh
pnpm build
node --test tests/sidebar-motion.test.mjs
```

浏览器检查默认使用 Windows 的 Chrome 路径；其他环境可通过 CHROME_PATH 指定浏览器。检查覆盖外框连续宽度变化、内容尺寸固定、原生位置对齐、快速反向开合、展开后的按钮命中、磨砂中间值与配置恢复。

已在实际桌面渲染器验证文件树目录可点击展开，重新展开后无残留交互锁，模糊过渡结束后恢复配置值。这些检查不代表整个应用零计算或所有入口都已逐一测试。
